# CLINICR 内部诊断流程

此页记录旧 L3 的设计，供今后在 ICD-10 路径上评估复用。当前运行入口使用 WHO ICD-10 树和临床复核。

1. **候选生成与取证**。Step 1 在同一次推理中生成候选和节点判断，记录命中的路径、逐节点结论、置信度、患者证据引用及缺失项。证据引用只能从画像、量表及患者原话生成的白名单选择。量表和已知临床字段提供线索，缺失证据保留为待核实。
2. **逐候选归类**。Step 2 确定性汇总 Step 1 的逐条判断。候选分为满足标准、待观察和排除。必需条目、排除条目、鉴别条件和病程约束参与归类。必需信息缺失时生成待补证据及追问计划。对满足标准的候选按初始置信度降序排列，同分用候选 ID 稳定排序。
3. **独立终验**。Step 3 只核验排序第一的合格候选，输入还包含其逐条证据与其他候选的鉴别结论。传给终验器的首选候选和节点记录移除了候选置信度。分别评估证据充分性、推理连贯性、鉴别覆盖和有无推理跳跃。总分至少 0.8 时通过，0.5 至不足 0.8 时输出暂定结论并要求补充项，低于 0.5 时退回 L2 并要求失败原因及补充项。首位候选的初始置信度低于 0.5 时单独阻止进入治疗匹配。
4. **补证与放行**。诊断信息报告区分证据覆盖、诊断就绪和追问计划，优先补充排名靠前且能区分候选的缺失节点。候选置信度与独立终验分数分开保存。候选未就绪时退回 L2，达到回流上限后转人工复核。
