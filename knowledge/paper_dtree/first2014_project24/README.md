# 24 标签决策树：PDF 检索与生成说明

本版：19 棵独立诊断家族树、225 个二元判断节点、24 个最终可输出标签。树数由家族及分型关系确定，没有沿用 18/28 棵上限。

本版依据 First 2014 鉴别诊断手册及用户提供并标注为 DSM-5（APA，2013）第 59–60 页的 ADHD A–E 摘录生成；年龄相关数量另参照 APA 官方资料。DSM 正文原版尚未独立核验。它是本地改编，不是作者未提供的优化附件，也不声称已完整重建 DSM-5 标准。coverage=partial 的具体缺口见下方说明。

## 执行顺序

病例 → 全部 24 入口筛选 → 所有适用家族树进入共享节点队列 → 各树按 yes/no 分支推进 → 汇总并去重候选 → 所有无序候选对逐一比较。没有先跑完一整棵再跑下一棵。

这仍是七阶段中的第 2 阶段。第 3–7 阶段继续保留原始输出、简化、匹配、人工协调及评分；24 标签指标应保留分型，与论文去修饰项的指标分开。

## 核心边界

- 原书允许共病；只把明确排他/完全解释同一症状的条件作为终止条件。保留 MDD/PDD、失眠/抑郁以及进食/情绪等可共病关系。
- 物质/药物、躯体生理病因及范围外疾病继续参与鉴别；不输出范围外候选，不把它们合并成最近的范围内标签。
- 同一情绪家族优先输出已支持的特征标签：D010 与 D008、D015 与 D013 不在同一条路径重复输出。基础标签不宣称已排除一切精神病性表现。
- ADHD 已逐项判断 A1/A2 各 9 项，并按年龄以程序计数后选择三种表现；单条症状的证据仍需核查。分裂情感性障碍仍需要明确分型记录；未明确时不强行归类。
- 适应障碍原表缺完整起病/持续期标准，设置明确核查节点。其余完整标准缺口逐项列在 source_gaps.json；本版不能替代完整 DSM-5 标准。
- source_verified 表示原文锚点可核查，不表示已经独立临床验证。stage=refined 表示本地改编，不表示论文作者的训练集优化已复现。

## 离线检查

本公开版不包含原始摘录与来源重建脚本，无法单凭此仓库重建完整本地研究档案。可以检查已包含的可执行树结构：

```powershell
.venv/Scripts/python.exe -m paper_dtree inspect --bundle knowledge/paper_dtree/first2014_project24/refined_bundle.json
.venv/Scripts/python.exe -m pytest -q tests/test_project24_trees_2014.py
```

当前主 CLI 默认加载本目录的 refined_bundle.json 和 entry_profile.json，使用 method=dt。旧 18 棵树包及专用工具已按用户要求删除；历史实验快照和费用记录保留。本次未发起付费测试。

label_catalog.json 是 24 个输出标签的绑定表，不是 --catalog 所需的 Appendix C 后处理词表。完整七阶段运行还需单独选择和审核后处理词表；若按论文删除分型/修饰项，24 标签会合并，不能将该分数冒充项目 24 标签指标。
