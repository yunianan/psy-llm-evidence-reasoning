# Public export scope

The default executable forest, entry profile, labels, source document IDs, and page numbers are included.
The original source pages, table transcription, source text anchors, and the raw speech-tree transcription are not included in this public repository export.
The `before`, source-note and table-text fields in the executable bundle and source audit are redacted; clinical questions, node IDs, branches, and source page references are retained.
Consequently the source extraction/rebuild tests are explicitly skipped here; source-level audit and reproduction require separately obtained authorized source material and the local full research archive.
Patient-case logs and local experiment outputs are not published in this update. The local working files are unchanged.
